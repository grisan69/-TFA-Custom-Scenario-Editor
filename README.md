# -TFA-Custom-Scenario-Editor
Custom Scenario Editor MOD for Task Force Admiral

Description
The Custom Scenario Editor is a community-developed MOD for Task Force Admiral, designed to give players greater freedom to create and customize their own naval battles.
Players can recreate historical engagements, explore alternative-history scenarios, or design entirely fictional battles through an intuitive graphical interface.
The editor allows users to customize participating fleets, aircraft, formations, starting positions, and various scenario settings without manually editing game files.
The public version focuses on compatibility with vanilla game content and does not require my personally developed ship or aircraft MODs.
This project has been developed and shared with permission from the Task Force Admiral developers.
My goal is to expand the game's replayability and give the community more opportunities to create and enjoy unique naval battles.

Installation
Make sure Task Force Admiral is installed through Steam.

Fleet Customization
Select and deploy individual warships.
